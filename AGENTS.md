# Repository Instructions

## Documentation language

- Write all repository documentation in English.
- Translate any existing non-English documentation into English, preserving its meaning and structure.
- When editing documentation, translate any non-English text in the document into English as part of the update.

## Agent collaboration

- At any point, delegate tasks to other agents using the collaboration tools when parallel work could save time or improve quality. This applies to both root agents and subagents.
